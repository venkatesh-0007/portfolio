### [02] Smart Drop
A seamless browser extension providing a modern, Apple-inspired floating vault for drag-and-drop file management, deep Google Drive integration, and instant AI text summarization.
* **Stack**: `JavaScript` `Manifest V3` `IndexedDB` `Shadow DOM`
* [View Repository ↗](https://github.com/venkatesh-0007/Smart_Drop)
